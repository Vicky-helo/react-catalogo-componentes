# react-catalogo-componentes

Atividade de React sobre componentes, props e reutilização.

## Tecnologias

- React
- Vite
- JavaScript
- CSS

## Como executar

```bash
npm install
npm run dev
```

## Componentes

- Cabecalho
- CardCurso
- Destaque
- Rodape

Os cursos são armazenados em um array e exibidos usando `map()`.
